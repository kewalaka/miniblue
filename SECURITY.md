# Security policy

## Important note

miniblue is a local development tool. It is not designed for production use and should never be exposed to the internet.

## Reporting a vulnerability

If you discover a security vulnerability, report it privately:

1. Do not open a public issue.
2. Email devopsbymo@gmail.com.
3. Include a description of the vulnerability and steps to reproduce it.

We will respond within 48 hours and work with you to understand and address the issue.

## Scope

Because miniblue is a local emulator, security concerns focus on:

- Preventing unintended network exposure
- Keeping mock tokens distinct from real Azure tokens
- Handling user-provided data safely in the in-memory store
